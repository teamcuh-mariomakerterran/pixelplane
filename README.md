# PixelPlane

Cyberpunk infinite-canvas pixel studio + City Engine.

Private safety backup. Studio, wires, mutation rails, craft lab (boil / tile kit / QA), City Engine juice, granular SFX, spatial pan, and city ambient beds.

## Run

```bash
npm install
npm run dev
```

Listens on `0.0.0.0:8080`.
